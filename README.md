# Zombie Apocalypse Salju

Modpack Forge 1.20.1 bertema survival zombie di dunia yang seluruhnya membeku.
Dunia salju, suhu dan kehausan, horde tiap 10 hari, zombie yang makin berbahaya
seiring hari, mutant mulai hari 30, dan loot-driven exploration.
